TeleGlance for TypeScript

A typed async client for public Telegram channels. No API key, MTProto credentials, or Telegram account.

Install

TeleGlance supports Node.js 18 and later, with ESM, CommonJS, and TypeScript declarations included.

Bash
npm install teleglance

Your first request

TypeScript
import { TeleGlanceClient } from 'teleglance';

const client = new TeleGlanceClient();
try {
  const channel = await client.getChannel('telegram');
  console.log(channel.title, channel.counts.subscribers);

  for await (const message of client.iterMessages('telegram', { limit: 10 })) {
    console.log(message.id, message.date, message.text.slice(0, 80));
  }
} finally {
  await client.close();
}

Messages, search, and live updates

History is yielded newest first. Use before for older history, after for forward-only updates, and search for Telegram preview search.

TypeScript
for await (const message of client.search('telegram', 'release', { limit: 20 })) {
  console.log(message.url);
}

for await (const message of client.watch('telegram', { interval: 30_000 })) {
  console.log('new post:', message.id);
}

JSON capture

Use the exported helpers for durable captures. captureJson writes formatted JSON safely and refuses to replace an existing file unless you opt in; appendJson adds one NDJSON record for long-running streams.

TypeScript
import { captureJson, appendJson } from 'teleglance';

const messages = [];
for await (const message of client.iterMessages('telegram', { limit: 50 })) {
  messages.push(message);
}
await captureJson(messages, 'telegram.json');

// For a stream created with captureJson([], 'watch.ndjson', { ndjson: true }):
await appendJson({ id: 42, text: 'A new post' }, 'watch.ndjson');

CLI

The teleglance executable prints JSON by default. Use --ndjson for record streams and --output to save a capture. Existing files are protected unless --overwrite is supplied.

Bash
teleglance channel telegram --output channel.json
teleglance messages telegram --limit 100 --output history.json
teleglance watch telegram --output watch.ndjson --overwrite
