API Reference

Detailed specifications of the classes, client methods, data models, and custom exceptions in TeleGlance.

TeleGlanceClient

The main client interface for communicating with Telegram web previews.

Constructor

Python 
class TeleGlanceClient:
    def __init__(
        self,
        *,
        base_url: str = "https://t.me",
        rate_limit: float = 1.0,
        retries: int = 3,
        timeout: float = 15.0,
        proxy: str | None = None,
        headers: dict[str, str] | None = None,
        request_hooks: list[RequestHook] | None = None,
        response_hooks: list[ResponseHook] | None = None,
        registry: ParserRegistry | None = None,
        selectors: Selectors | None = None,
        transport: TransportProtocol | None = None,
        strict_parsing: bool = False,
    )
Parameter Type Default Description
base_url str "https://t.me" Target URL for Telegram previews.
rate_limit float 1.0 Maximum requests per second. Set to 0 to disable throttling.
retries int 3 Number of retry attempts on HTTP failure or 429 status codes.
timeout float 15.0 Request timeout in seconds.
proxy str | None None Proxy server URL — HTTP, HTTPS, SOCKS4, or SOCKS5.
headers dict | None None Custom headers merged into every request.
request_hooks list | None None Callbacks executed before each request is sent.
response_hooks list | None None Callbacks executed after each response is received.
registry ParserRegistry | None None Registry containing custom parsing functions.
selectors Selectors | None None Custom Selectors mapping for HTML extraction.
transport TransportProtocol | None None Custom transport layer implementation.
strict_parsing bool False When enabled, recognized pages with no posts raise ParseError instead of returning empty lists.

Async Methods

get_channel

Retrieve metadata details for a public Telegram channel.

async def get_channel(self, channel: str) -> Channel
Parameter Type Description
channel str Target channel identifier (e.g. name, @name, or t.me link).

Raises: ChannelNotFound if the channel does not exist. ChannelPrivate if the channel is private.

get_message

Fetch a single message by ID.

async def get_message(self, channel: str, msg_id: int) -> Message
Parameter Type Description
channel str Target channel identifier.
msg_id int Message ID to search for. Must be a positive integer.

Raises: MessageNotFound if the message does not exist or has been deleted.

iter_messages

Iterate channel posts backwards (newest to oldest).

async def iter_messages(
    self,
    channel: str,
    *,
    limit: int | None = None,
    before: int | None = None,
    query: str | None = None,
) -> AsyncIterator[Message]
Parameter Type Default Description
channel str — Target channel identifier.
limit int | None None Maximum number of messages to yield.
before int | None None Message ID cursor — yields posts strictly older than this ID.
query str | None None Filter messages by keyword search.

iter_new_messages

Iterate channel posts forwards (oldest to newest).

async def iter_new_messages(

) -> AsyncIterator[Message]
Parameter Type Default Description
channel str — Target channel identifier.
after int — Message ID cursor — yields posts strictly newer than this ID.
limit int | None None Maximum number of messages to yield.

search

watch

Start a live poller that continuously yields new posts.

def watch(
    self,
    channel: str,
    *,
    interval: float = 30.0,
    since_id: int | None = None,
) -> AsyncIterator[Message]
Parameter Type Default Description
channel str — Target channel identifier.
interval float 30.0 Polling interval in seconds.
since_id int | None None Filter posts newer than this ID. Defaults to the newest post ID found on startup.

Data Models

Pydantic V2 models returned by TeleGlance client methods.

Channel

Represents public Telegram channel details.

Field Type Description
username str Target handle of the channel.
url str Direct t.me/s/ URL.
title str Title of the channel.
description str | None Text description.
description_html str | None HTML description.
avatar_url str | None Channel avatar image URL.
counts ChannelCounts Approximate subscriber and media attachment counters.

Message

Represents a single Telegram post.

Field Type Description
id int Unique message ID.
channel str Channel handle.
url str Direct message URL.
date datetime | None Publish timestamp.
views int | None Estimated view count.
views_str str | None Raw views text (e.g. "1.2K").
author str | None Signature of the post author.
text str Plain text content.
html str | None Inner HTML of post content.
markdown str | None Lossy markdown formatting.
entities list[Entity] Text styles, hyperlinks, and mentions.
media list[Media] Media attachments.
reactions list[Reaction] Active emoji reactions.
raw_html str Complete HTML node string (preserved for custom parsing).

Custom Exceptions

TeleGlanceErrorBase package exception. All library errors inherit from this.
InvalidChannelRaised when the channel identifier format is invalid.
ChannelNotFoundRaised when a public channel cannot be found on Telegram.
ChannelPrivateRaised when a channel is private or web previews are blocked.
MessageNotFoundRaised when a specific message ID does not exist or was deleted.
ParseErrorRaised when the parser fails to understand the page layout.
RateLimitedRaised when requests exceed Telegram rate limits after all retries.
DownloadErrorRaised when media downloads fail or exceed the size limit.
CheckpointErrorRaised when reading or writing checkpoint state fails.
