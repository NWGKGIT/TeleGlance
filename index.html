TeleGlance

Async Python client for public Telegram channels built entirely on t.me web previews. No API keys. No MTProto. No user account required.

Get Started API Reference GitHub
$ pip install teleglance

Also available for Node.js: npm install teleglance → TypeScript guide

Python 
import asyncio
from teleglance import TeleGlanceClient

async def main():
    async with TeleGlanceClient() as client:
        channel = await client.get_channel("nahomssandbox")
        print(channel.title, channel.counts.subscribers)

        async for message in client.iter_messages("nahomssandbox", limit=10):
            print(message.id, message.date, message.text[:80])

asyncio.run(main())

Features

No API Keys Required
Access public channel data directly via t.me web previews, no Telegram developer account needed.
Live Polling
Watch channels for new posts with configurable polling intervals. Transient errors are retried automatically.
Resumable Checkpoints
Built-in JSON checkpoint store lets you resume scraping exactly where you left off after crashes or interruptions.
Media Downloads
Download photos, videos, stickers, and voice notes directly to disk or into memory with size limits and overwrite control.
Typed Models
All results are Pydantic v2 models, Channel, Message, Mediafully type-annotated and validated.
Extensible & Resilient
Override CSS selectors, register custom parsers, add request/response hooks, no library edits needed.

Why TeleGlance?

TeleGlance is not a replacement for Telethon. It provides a deliberately smaller interface for applications that only need publicly accessible channel data and do not want Telegram API credentials or an MTProto session.

Capability TeleGlance Telethon
Telegram API credentials No Yes
MTProto No Yes
Public channels Yes Yes
Private channels No Yes
Full Telegram API No Yes
Web-preview based Yes No
Account / session required No Generally
Sending / interacting No Yes

Limitations

  • Cannot access private channels or groups — raises ChannelPrivate
  • Cannot send messages or interact with chats
  • Cannot download document attachments (no direct URL in web previews)
  • History depth is capped by Telegram's preview depth (typically ~100–2,000 posts)
  • View and subscriber counts are approximate strings (e.g. "1.2K")
  • Markup changes to Telegram's web preview may require selector overrides
